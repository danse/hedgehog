# Skills

Reusable OpenCode instructions for agent work on this repo. Registered from
the root `opencode.json`, so the files here are discovered without a hidden
`.opencode/` directory.

| Skill | Purpose |
|---|---|
| `hedgehog-live/` | Live-session protocol: handovers, landings, voice overflows and safe verification. |
| `hedgehog-develop/` | Development-mode protocol: every block counts, static feedback, spine browsing and public-repo care. |
| `contributors/` | Curated local index of outside Tidal tune clones: styles, worth-reading sets and what Hedgehog borrowed. |

Keep skills to stable, reusable workflow. Session-specific plans and unvetted
preferences belong in `notes/`, not here. See `../../AGENTS.md` for the project
rules the skill points back to.
